Nothing here was hand-picked. For every subtype we sort all units that both models were judged on into three buckets — both correct, split, both wrong — and show the first member of each bucket in sha1(item_id::event_id::window) order. The rule is fixed in advance, so the page contains failures at the same rate the benchmark does. Each card states how many units its bucket holds. Where a bucket is empty the card says so; nothing is substituted from a neighbouring bucket.
Device turns have no reference answer. Their ground truth is a behavioural contract — stop and answer, or keep going — so those cards show the contract and what the model was mid-sentence on when the user cut in, rather than a target string.
Known confound, unchanged from the main results. Gemini receives the sealed row's system prompt; MiniCPM does not, because the runner never reads that field. The MiniCPM column is prompt-deprived and is not a like-for-like comparison.
